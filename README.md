### 🎯 No que eu foco

- **Python na prática** — automações, scripts de sistema e análise de dados.
- **Desenvolvimento web** — interfaces dinâmicas e APIs com JavaScript/TypeScript e Django.
- **IA aplicada** — integração de modelos via API para resolver problemas concretos.
- **Fundamentos de cibersegurança** — segurança defensiva, boas práticas e proteção de dados desde o design.
